# HealthTrend

Android app for structured medical test records and trend visualization.

## Development source of truth

Read [`docs/PRODUCT_RULES.md`](docs/PRODUCT_RULES.md) before changing the app. It is
the product-level requirements entry and links to the detailed domain rules.

## v0.1 goals
- Full lab report preservation with original images
- Editable recognized values
- Hospital-specific confirmed unit/reference templates
- Primary CBC/liver/kidney trend cards while retaining all recognized metrics
- Symptom and medical-record timeline
- In-app update path

Builds are produced by GitHub Actions on main.
