# 统一指标标准池｜逐项医学审核台账（2026-10-14）

> **本表来自当前 `UnifiedMetricStandard.kt` 的真实代码定义，是逐项审核底稿，不是全部已获权威资料验证的证明。** 旧报告数据、原单位和原始参考范围不得为满足本表而重写。

## 审核原则及正式资料

- LOINC（Regenstrief）用于检验观察项的准确身份；判断是否同一指标，需要同时考虑检测对象、测量属性、标本、时间、方法等，不能只靠中文近似名或英文缩写。[LOINC 官方](https://loinc.org/about)、[代码结构](https://loinc.org/kb/faq/structure)。
- 参考范围因实验室和人群不同而变化，不得把外部通用范围自动灌入患者报告。参考当次报告实际范围；单位变换须同时变换结果和上下限。[MedlinePlus：理解检验结果](https://medlineplus.gov/lab-tests/how-to-understand-your-lab-results/)、[综合生化](https://medlineplus.gov/ency/article/003468.htm)。
- 下表的英文 ID 是 **App 内部身份**，不是已认证的 LOINC 代码；表中常用单位也不能冒充特定实验室的法定唯一单位。对于不同标本、检测方法或同码多义（如 PCT、CKMB、D-Dimer、肌钙蛋白等）必须单独核对报告，再确定合并与转换。
- **已完成的静态审核**：枚举当前代码所有指标；核对 ID 和中文名称是否重复、缺失；增加自动化测试防止相似身份/别名盲目合并。
- **尚缺的医学审核**：每一项的具体 LOINC/专业检验依据、标本与检测方法、可接受单位/转换、别名是否过宽、参考范围个体适用性。没有逐项证据时一律保持「待逐项核验」，不得对外宣称 110 项已临床审定。

### 特别核查发现
- [LOINC 官方 CBC 自动血常规面板](https://loinc.org/58410-2)明确列出 WBC、RBC、HGB、HCT、MCV、MCH、MCHC、PLT；这些项目在**全血自动计数**情况下可对应特定术语，其他方法不得强行套用。
- [LOINC 官方白细胞分类面板](https://loinc.org/57021-8/panel)单列中性、淋巴、单核、嗜酸、嗜碱细胞的绝对计数，不能与相应百分比混合。
- [LOINC RDW 21000-5](https://loinc.org/21000-5)现标注 **Deprecated**，并指向 RDW-CV `115741-1` 与 RDW-SD `115742-9`；它们不能共用旧歧义代码。
- [LOINC D-Dimer 指引](https://loinc.org/kb/users-guide/loinc-technical-briefs/d-dimer-revisions-in-loinc)指出 FEU 与 DDU 不能仅按文本里的“D-Dimer”视为同一计量标准。此前 `DDIMER` 未预设单位是谨慎选择，必须保留。
- [MedlinePlus CBC](https://medlineplus.gov/lab-tests/complete-blood-count-cbc/)和[分类计数](https://medlineplus.gov/lab-tests/blood-differential/)支持上述概念区分，但不代表特定医院或患者的参考区间；**禁止使用通用范围覆盖真实报告**。
