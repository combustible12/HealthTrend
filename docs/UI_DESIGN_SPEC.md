## 纯色底色块

所有界面控件采用纯色背景，不使用线框、描边或轮廓线：按钮、选项、卡片、输入框、日期输入、弹窗及其焦点/未选中状态均适用。用纯色背景、文字和留白区分层级与选择状态。不要让组件库默认的OutlinedButton、FilterChip未选中边线、OutlinedTextField焦点线重新出现。可通过统一主题/包装组件或显式透明border实现，避免只修某个单独画面。

检验曲线和参考范围边界属于数据表达，不是控件装饰边框，本规范不要求去除数据线条。
