## 纯色底色块

所有界面控件采用纯色背景，不使用线框、描边或轮廓线：按钮、选项、卡片、输入框、日期输入、弹窗及其焦点/未选中状态均适用。用纯色背景、文字和留白区分层级与选择状态。不要让组件库默认的 OutlinedButton、FilterChip 未选中边线、OutlinedTextField 焦点线重新出现。不得用透明边框或背景同色边框伪装无描边；输入组件必须从 `BasicTextField` 构建真实的纯色表面。

检验曲线和参考范围边界属于数据表达，不是控件装饰边框，本规范不要求去除数据线条。

## 输入组件实现约束（2026-10-28）

全 App 使用 `AppInputField` 体系：字段名固定在实色输入区外部左上方，圆角输入区不生成轮廓线或底部指示线。业务源码不得直接使用 `OutlinedTextField`、Material `TextField` 或 `BasicTextField`；`BasicTextField` 仅允许存在于公共输入组件文件。筛选项必须显式 `border=null`，描边按钮必须替换为纯色按钮。持续集成和正式发布均执行自动阻断检查。
