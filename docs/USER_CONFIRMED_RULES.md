## 2026-10-16 词典精准定位补充约束
- **必须精准定位，不允许“相似医学术语/近似 LOINC 编码”被当作确认通过**。LOINC 如有不同测量属性（质量浓度/物质浓度、活性/质量浓度）、计算法/直接法或 FEU/DDU，必须精确区分；不能靠同名、单位可换算或别名类似擅自绑定。

- **D-二聚体**：FEU 与 DDU 必须区分，不可按相同数字视作同一量，不可自行套一个固定比例重写历史值。

## 2026-10-27｜病程标题、放化标签与港维护

1. 病程卡片标题只用于日期旁的放化疗进度，不把症状内容写入标题。
2. 自动标题仍可手动修改；手动修改后该日标题保持用户输入。
3. 标记“化疗”或“化疗日”时进入下一化第 1 天，后续按自然日递增；21 天不是强制重置点，只有下一次实际化疗才重置。
4. 标记“放疗”时累计一次放疗并在当天显示“放N”；未放疗的当天不显示任何放疗次数。
5. 新增“放化”标签：同日进入下一化第 1 天，同时把放疗累计次数加 1。放疗累计次数不重新计算、不归零。

7. 病程列表顶部显示纯色横条：“港维护　MM/DD　→　MM/DD　已维护”。
8. “港维护”、左侧日期、箭头和“已维护”为细体，右侧下一次日期为粗体；“已维护”只是可点击文字，不加按钮色块或描边。
9. 左侧维护日期可手动选择；右侧日期按 28 天生成。点击“已维护”后，原右侧日期转为左侧日期，再顺延生成新的右侧日期。
