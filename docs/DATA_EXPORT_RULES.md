# HealthTrend｜检验报告数据提取与导出规范

版本：V1.0（2026-10-23）  
状态：持续维护；修改本文件并提交 Git 历史  
范围：仅 HealthTrend；不修改其他仓库

## 1. 责任边界
- **导出方负责**逐项识别原始报告、确认标准指标身份、完成所有可靠单位换算、同步换算参考范围、复核后生成可直接粘贴进 HT 的文本。不得把换算责任转交 HT。
- HT 负责存储、读取、趋势呈现；不能借由趋势图的单位兼容机制掩盖错误导出。
- 原始医院、日期、项目名称、原始数值/单位/参考范围/异常提示应能追溯。不可虚构缺失值、临床阈值、医院参考范围；待核实项目另列，不静默跳过。
- 同单位≠同指标；同指标≠检验方法一定可比。多个医院只在身份及方法可比时合并趋势，各自参考范围独立保留。

## 2. 导出流程
1. 精确读取医院名、采样/检验日期、报告类别（报告日与检验日不同时说明）。
2. 提取全部项目和原文异常标记，与原件逐行核对。
3. 以**标准中文名+必要的测量类型**确定身份；英文代码/别名仅辅助识别，医院仅作来源标签。
4. 判定原单位与指标标准单位，记录换算公式和原值；数值及上下参考限必须同步换算。
5. 确定报告项目自身的正常/异常信息；缺乏完整参考范围时不伪造。
6. 输出 HT 约定格式，独立列出未能确认的单位、指标、数值及原因；再做逆向核对。

## 3. 常见统一写法
- ug、µg、μg、mcg → μg；ul、µL、μL → μL；fl → fL；mg/l → mg/L；g/l → g/L；mmol/l → mmol/L。
- 10*9/L、10^9/L → 10^9/L；10*12/L、10^12/L → 10^12/L。
- 单位大小写、SI 前缀不能盲目统一：mIU ≠ IU；mg ≠ μg。
- 同量纲单位换算：g/dL ×10 → g/L；mg/dL ×0.01 → g/L；mg/L ÷1000 → g/L；μg/mL = mg/L；ng/mL = μg/L；pg/mL = ng/L；10^3/μL = 10^9/L；10^6/μL = 10^12/L；mIU/L = μIU/mL。
- 每个项目的最终单位优先沿用 HT 现有标准单位；**没有确认历史标准单位前，不得自行更换标准单位**。

## 4. 按分析物换算（仅对应具体项目，不能推广到同单位的其他项目）
| 分析物 | 原单位 → 目标单位 | 计算 |
|---|---|---|
| 葡萄糖 | mg/dL → mmol/L | ÷18.018 |
| 肌酐 | mg/dL → μmol/L | ×88.4 |
| 尿酸 | mg/dL → μmol/L | ×59.48 |
| 尿素氮(BUN) | mg/dL → 尿素 mmol/L | ×0.357（需确认身份/报告表述） |
| 总胆固醇 | mg/dL → mmol/L | ÷38.67 |
| 甘油三酯 | mg/dL → mmol/L | ÷88.57 |
| 总/直接胆红素 | mg/dL → μmol/L | ×17.1 |
| 钙 | mg/dL → mmol/L | ×0.2495 |
| 磷 | mg/dL → mmol/L | ×0.3229 |
| FT4 | ng/dL → pmol/L | ×12.87 |
| FT3 | pg/mL → pmol/L | ×1.536 |

系数为通行近似值；计算时保留高精度中间值，导出保留足够有效位以避免错误越界；所涉检验方法和测量对象不明时禁止推断换算系数。

## 5. 血常规及身份约束
- WBC/NEUT#/LYMPH# 等白细胞绝对数、PLT → 10^9/L；RBC → 10^12/L；HGB/MCHC → g/L；MCV/RDW-SD → fL；MCH → pg。
- NEUT%、LYMPH%、HCT、PCT（**血小板压积**）、RDW-CV → %。HCT 原值 L/L ×100 → %，上下限也 ×100。
- **RDW-CV (%)、RDW-SD (fL) 必须分开**；PDW 的 % 与 fL 记录按已确认分类分开，不因名称相近强制混合，也不擅自把所有 PDW 命名为 CV/SD。
- PCT 血小板压积与 PCT 降钙素原完全不同；P-LCR 比率与绝对数量不同。
- CK-MB 活性与质量浓度、AST 与 AST/ALT 比值、尿素与尿素氮、白细胞百分比与绝对计数不得混作一个身份。
- 保留 CA72-4、FT4 等名称完整字符及标记。

## 6. D-二聚体 FEU/DDU
- 已确认的趋势身份仅为 **D-二聚体（FEU）** 与 **D-二聚体（DDU）**；不同身份分卡、不连线。
- 同类型下：1 mg/L = 1 μg/mL = 1000 ng/mL = 1000 μg/L（需附随 FEU 或 DDU 标识）；例如 0.22 μg/mL FEU = 0.22 mg/L FEU。
- FEU/DDU 有约 2:1 名义关系，但跨方法不保证可比；**不自动相互换算、合并历史趋势**。
- 报告未注明 FEU/DDU 时根据报告或院方方法确认；无法确认则列待核实，不额外创设“未标注”第三种趋势身份。

## 7. 参考范围与特殊结果
- 原始结果及参考范围应用**同一个**转换系数：如 4.2 g/dL、3.5–5.5 g/dL → 42 g/L、35–55 g/L。
- 保留原报告单侧边界表达：0.108--、--12.10；不凭空增加另一侧限值。不得把历史错误的 ≥0.108 或 ≤0.25 等边界重新猜补。
- <1、>200、≤0.25 等结果必须保留比较符号，按单位换算阈值，不把阈值当精确测量结果。
- 阴/阳/弱阳/可疑按定性结果保存，不能赋值 0/1；不能凭空生成数值。
- 原报告无箭头可记“未标异常”，但不能在未知参考范围时无条件宣称正常。冲突标记列待核实。
- 同一天多次采样保留时间及全部记录，不做未经授权的平均或合并。

## 8. HT 粘贴导入格式
普通报告：
```text
医院名称
血常规
YYYY-MM-DD
WBC 白细胞计数 8.42 10^9/L 3.5-9.5
NEUT# 中性粒细胞计数 6.21 10^9/L 1.8-6.3
```
*以上数值仅为格式示例，不是用户历史数据。*

报告明确存在组合小类时，在日期前额外增加小类行：
```text
医院名称
传染病筛查
乙肝二对半（定性）
YYYY-MM-DD
...
```
必须以 HT 现有导入解析器实际支持的格式为准，不任意在记录行加字段破坏解析。原始信息及转换记录若不能放入当前导入文本，另行保留核对清单。

## 9. 导出验收
- [ ] 医院、类别、小类、日期正确
- [ ] 原件项目全部有去向，无静默遗漏
- [ ] 代码、标准中文名、身份无混淆或截断
- [ ] 单位与历史统一单位一致
- [ ] 所有结果、上下限同系数换算，符号保留
- [ ] FEU/DDU、RDW/PDW、PCT、CK-MB 等特殊项已确认
- [ ] 未确认项明确列出、不猜测
- [ ] 最终文本经 HT 导入解析器兼容验证（如未验证，明确标记待验证）
- [ ] 所有历史可追溯，不自动覆盖报告原始数值

## 10. 维护与变更
本文件是 **导出规则**，不直接改变 APP 代码。未来增加指标/系数或修改标准单位时：先核对检验依据和历史身份，补充换算测试用例，再修改同一文件提交 Git。若需同步修改 HT 代码或数据库迁移，另开明确变更并验证旧数据兼容。不要将临时异常值判断升格为通用换算规则。
