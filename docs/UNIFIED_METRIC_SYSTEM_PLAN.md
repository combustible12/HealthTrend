## 2. 统一指标身份与项目池
- [ ] 设计稳定内部指标 ID（不可因名称/代码变化而变化），兼容旧 metricKey；英文缩写只作为标准代码或识别线索。
- [ ] 按检查类型维护统一可扩展项目池（血常规、生化等），不再要求每家医院独立维护重复的指标全集。
- [ ] 保留一个固定常用中文显示名；维护英文代码、中文/英文别名及来源医院原名。
- [ ] 以权威检验资料和设备参数为依据，尽量扩充血常规、生化常见及扩展指标，逐项去重核验；不假设固定最大数量。
- [ ] 区分名称不同但身份相同的指标，以及 AST/ALT 与 ALT/AST 等身份不同的指标；比值方向精确匹配，不删斜杠、不排序。
- [ ] 无公认英文代码的新指标自动生成唯一自定义内部代码，不伪造医学缩写；用户确认后加入项目池。
- [ ] 同一指标可被不同检查类型引用；医院差异和报告当次单位/参考范围仍独立保存。

## 3. 标准化导入、核对与保存
- [ ] OCR、粘贴、手动录入使用统一匹配引擎与标准中文名称。
- [ ] 匹配优先级：明确已确认映射 → 标准名/精确别名 → 精确代码/比值 → 名称+单位+类型综合判断 → 顺序仅辅助；歧义则待核对，不猜。
- [ ] 不同医院报告中的 B 名称转换成 App 固定 A 名称；对外导出固定粘贴格式（医院、检查类型、YYYY-MM-DD、代码 中文名 结果 单位 参考范围）。
- [ ] 模板外项目可保存：已知统一指标自动归并；未知项目允许确认中文名称/结果后新增，或仅保存本次报告。
- [ ] 项目数量不同不阻止保存；未检测项目不自动生成或补零；新项目不得自动污染人工确认模板。
- [ ] 校验只拦截真实无效数据，指出具体行及原因；支持编辑、删除、暂存待核对项目，不因单项问题锁死整份报告。
- [ ] 保留原始结果精度、displayUnit、canonicalUnit、参考范围、医院、日期及报告来源；不得擅自增加单位乘号。
- [ ] 检验导出名称与 App 实际导入词典一致；考虑词典配置导出/导入以同步用户本地自定义别名。

## 4. 别名注释、管理与搜索
- [ ] App 内可查看、添加、编辑、删除别名；修改后持久化，重启和升级后保留，不需发新版 APK。
- [ ] 别名冲突检测：同一别名可能对应不同指标时不能静默合并，必须提示核对。
- [ ] 搜索标准名、中文别名、英文缩写都命中同一个标准指标，不创建重复卡片。
- [ ] 搜索结果指标卡片**上方**显示别名注释模块：高亮当前命中的别名，同时显示其他别名，明确“B 名称对应 A 标准名”。
- [ ] 允许点击名称/注释查看完整别名；趋势、历史、添加项目、指标管理等入口共用搜索规则。
- [ ] 用户新增的别名既可搜索也可参与导入识别；支持手动维护，不需要反复让助手改代码。

## 5. 旧数据兼容、历史报告与趋势
- [ ] 不删除旧医院模板、不覆盖人工确认结果；旧模板仅转为兼容/来源信息，迁移先用副本验证。
- [ ] 不批量修改旧报告 metricKey、值、单位、精度、参考范围、日期、图片或医院；以映射层兼容旧数据。
- [ ] 不同医院的同一指标正确归入趋势，但医院分段、颜色、参考范围硬接、单点、未测断线规则保留。
- [ ] 防止同名异义、方向相反的比值被合并；检查重复 ID 与历史异常值。
- [ ] 升级后历史报告、图片资料、趋势、编辑和删除功能全部正常；迁移失败保留原始数据。

- 已读取当前 `ReportParser.kt`、`Editors.kt`、`HealthStore.kt` 和本计划，未改写任何历史数据或模板。

- **发现 2**：`metricIdentityKeys` 含 `AST/ALT`，但未包含 `ALT/AST`；需要补充独立身份及全链路测试，不能简单互换。
- **发现 3**：`ReportDraft.valid` 对新报告要求每行 `!uncertain` 且有中文名称；`DraftRow.from` 会因缺失结果或仅有单侧参考范围标记 uncertain，存在将数据问题与新指标身份混为一谈的风险。
- **发现 4**：`HealthStore.saveReport` 允许模板外项目保留在本次报告，不强制报告数量等于医院模板，但核对页仍可能阻止保存。应优先修通核对层和存储层的契约。
- **发现 5**：`ReportParser` 的 `canonicalUnits` 包含 `×10^9/L` 等，需验证是否与既定 displayUnit 不自动加乘号的显示规则冲突。
- 本轮状态：**已开始阶段 1，完成初步静态审计；尚未实现重构、编译、发布或用户验收**。
- 下一步唯一任务：在保留旧数据的前提下，修正报告核对与保存契约，补充对应单元测试；随后扩展统一指标身份和别名持久化。
