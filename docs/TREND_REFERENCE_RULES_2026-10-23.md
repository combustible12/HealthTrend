# HealthTrend 趋势图与参考范围规则（2026-10-23）

## 数据完整性
- 趋势图必须以已保存的检测记录为数据源，而非参考范围池；每条有效定量结果都应绘制数据点，包括无参考范围、单边参考范围、不同医院以及同日多条记录。
- 图表记录数应与同一标准指标身份下的有效报告结果数一致；不得因日期去重、医院过滤、单位缺失、异常状态或图表视口而丢点。
- 最新值必须对应趋势图中实际存在的最新记录。不同单位仅在同一指标身份且可安全换算时统一；原始值、原始单位和原始报告不可被覆盖。

## 参考范围
- 每条记录独立关联当次报告的参考范围。不同医院及同医院不同日期可有不同范围；不允许拼接上下限。
- 完整双边范围：纵轴应包含所有有效上下限，显示两条边界虚线和中间浅色区域。图表及卡片高度可随数据密度调整，不能以固定高度裁掉完整边界。
- 原始单边范围：只绘制存在的边界虚线，正常区域延伸到画布边缘（边缘不是另一个参考边界），不补全或估算另一边；无范围则不画范围，但仍画数据点。
- 血小板压积特例：保留中医院原始 `0.108--`，不得额外派生并显示 `≥0.108` 作为独立范围。清理重复显示不得删除原始报告、检测值或合法历史记录。
- 未在报告中出现的单位不得自行补写；保留原始范围字符串，单位换算仅按现有同身份规则执行。

## 异常判断和颜色
- 对每条历史记录，优先保留医院明确标记的 ↑/↓；医院明确未标异常与导入文本遗漏异常标记必须区分。若医院标记与可核实的参考范围判断冲突，保留两者并提示核对，不能静默覆盖。
- 完整范围按上下限判断；单边范围只对已知边界作确定性判断，不能推测未知边界；无法判断为灰色。
- **同一指标身份全部历史任意一次确认异常，使用既定医院红色色阶；否则使用医院蓝色色阶。** 医院图例、点、平滑曲线同色；不允许统一 Bad 覆盖医院身份。无法判断异常不等于无效点。
- 卡片右上角最新值独立按最新记录判断，历史异常不得直接改变最新值颜色。
- 趋势颜色与参考范围虚线/背景是相互独立的显示逻辑。

## 验收
1. 报告详情与趋势图逐指标核对有效数值条数，含无范围、单边范围、同日多条和多医院数据。
2. `0.108--` 仅一条边界虚线；不得显示派生的 `≥0.108` 重复项。
3. 完整范围的上下边界均可见；卡片随需要自适应，不截断日期、数据点或边界。
4. 历史任一异常时使用各医院对应红色色阶；最新值颜色仅取最新记录。
5. 回归检查 RDW-CV(%)/RDW-SD(fL)、PDW-CV(%)/PDW-SD(fL) 身份规则及历史记录不被破坏。
6. 构建和测试通过后方可宣称发布成功。

## 统一投影与医院身份
- 医院归属来自每个报告 hospitalKey，trim 后分组，不按日期猜测。同一指标身份、已统一到相同有效计量单位且可比较时，不同医院的相邻数据允许连续连接；同检查类型缺测日期仍断线。
- 主图和整体预览共用 TrendGeometry 投影与分段；**必须使用经过真实数据点的连续平滑曲线，禁止用 lineTo 折线替代**。相邻点间的三次贝塞尔控制点应限制在相邻结果的纵值区间内，避免虚假峰谷和过冲；曲线允许跨医院但不得跨缺测断点或不同指标/单位身份；跨医院的曲线在中点平滑切换为另一医院既定颜色，不能抹去来源差异。整体预览中，仅无连线的独立单点显示圆点；处于连续曲线段中的所有记录（包括端点）仅由经过真实坐标的平滑曲线表达，不额外绘制圆点。记录不得遗漏。此条为用户确认的长期强制规则，未来重构不得回退到折线图。
- 医院色板槽位独立保存；新增医院只追加，重新排序、切换指标、删除报告均不重排旧医院槽位。六阶色板之后确定性扩展，不能按当前医院总数重新渐变。
- 原始结果换算为绘图坐标；旧 normalizedValue 不可覆盖原始值重新计算的结果。单位不同但兼容时数值与参考范围同倍率转换；不兼容单位另列序列，不隐藏记录。
- 主图及预览均保留同一日期每一条不同结果，并按报告 ID、结果 ID 稳定排列；同 ID 的重复输入不重复画点。

## 卡片顺序
- 每张卡片提供并列的左箭头与上箭头无边框图标；左箭头切换重点/其他分组，上箭头置于当前分组顶部。
- 顺序按完整趋势身份持久保存；指标、单位、FEU/DDU 任一不同都视为不同卡片。操作不改报告数据。

## 曲线不可退化回归（2026-10-23 用户再次确认）
- 生产趋势主图与整体预览统一使用受约束的三次贝塞尔平滑插值；真实点始终作为曲线端点，不移动、不删除，不产生相邻真实点之外的峰谷。
- 自动测试和代码审查需确认两处绘图入口都使用 cubicTo 曲线段，禁止替换成 lineTo 或绘制连接点的折线。
- 整体预览：单点分段只绘制点；连续分段只绘制平滑曲线，不绘制节点圆点（含曲线起止端点）。主图原有节点显示不受影响；不兼容的指标身份或连续性断点不插值连线；不为视觉平滑增加测量记录。

## 整体趋势图圆点显示强制规则（2026-10-23）
- **整体趋势图：有连线的记录只显示平滑曲线，不叠加任何节点圆点，包括首尾两端；只有单独、没有任何连线的记录显示圆点。**
- 按 TrendGeometry.segments 实际分段判断：长度 1 显示点；长度 ≥2 显示曲线、不画点。跨医院可比较数据连通；缺测断线时，按各自分段独立判断。
- 单独趋势卡片不应用此隐藏规则，保持其原有点显示和交互。
- 验收要分别检查孤立单点、两点连线、三点以上曲线、不同医院断段及缺测断段；规则调整不得删除记录或改变原始值。

## 跨医院连续趋势（2026-10-23 用户确认）
- 同一标准指标身份且计量单位已可靠统一、数值具有可比性时，允许跨医院连接；仅凭医院名称不同不准强制断线。
- 跨医院的贝塞尔曲线按相邻两端医院颜色在曲线中点切换，原有医院色板、点颜色与各报告参考范围均保留；不添加虚假的检验点。
- 不同指标身份、FEU/DDU、CV/SD、CK-MB活性/质量浓度等不合并；缺测日期仍断线。检测方法明确不可比时必须另外隔离，不能单凭单位相同判定可比。
- 整体预览中长度≥2的曲线段不叠加圆点；独立点单独绘制。主图保留点及点击交互。
