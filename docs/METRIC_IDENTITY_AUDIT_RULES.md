## A. 不可破坏的底线
1. **一个医学测量身份对应一个稳定 ID**。不同医院的同一指标使用统一 ID；医院只是来源元数据。**不再为新报告创建或更新医院模板**。
2. **不同医学属性必须分离**：绝对计数与百分比、CV 与 SD、浓度与活性、比值及其相反方向、不同标本/分母/方法不可仅凭词相近或共享英文缩写合并。
3. **此前已确认的身份规则必须首先核查**，不再等用户重复指出：`RDW-CV/RDW-SD`；`PDW-CV/PDW-SD`；`NEUT#/NEUT%` 等五类白细胞；`NRBC#/NRBC%`；`PCT/PCTIN`；`CRP/HSCRP`；`CK/CKMB/CKMB/CK`；`AST/ALT` 与 `ALT/AST`；`DDIMER` FEU/DDU；肌钙蛋白 I/T。
4. **原始报告不可被标准词典覆盖**：数值、原始小数位、原始单位（包括不带“×”的 `10^9/L`）、参考范围、日期、医院、原始图像、指标显示名称都要保留。内部标准化结果和展示原文分层，单位换算必须同时作用于结果与当次参考范围且关系确定。
5. 不得凭单位单独自动推定身份；当代码、中文名称、单位、必要的医学测量属性冲突时**标记待核对并阻止以错误身份保存**。人工明确确认后才能归属；不能随意替换单位掩盖冲突。
6. 参考范围以该次原报告为准；不同医院/仪器范围保持各自记录；**不得填入外部“通用正常范围”**。缺失项目不补零、不生成假结果。
7. 无法确定身份的新项目允许人工确认并注册永久 `CUSTOM-UUID`；不自动污染词典、不因未收录而丢弃整份报告。自定义身份持久化，禁止因中文名改变而重新生成 ID。
8. 历史确认报告、人工模板、病程 `course_records` 原样保留。任何兼容映射只能在**确认无歧义后只读关联**，不改写历史身份或历史数值；严禁以“历史已经存过这个名称”直接自动学习别名。
9. 后续**趋势图暂停修改**，除非用户重新明确要求。词典与医学核验不能借机改变趋势界面或病程功能。

## B. 每个指标的固定核验顺序（逐项执行，不跳步）
| 顺序 | 核验项 | 必须记录的证据与判定 |
|---|---|---|
| 1 | 当前源码身份 | 从 `UnifiedMetricStandard.kt` 逐项读取唯一 ID、标准中文名、同义别名、常用单位、所在检查类型；不依赖旧清单 |
| 2 | 已确认规则对照 | 对照本文件 A 节风险清单，检查是否遗漏 CV/SD、绝对值/百分比、比值方向等独立身份 |
| 3 | 官方医学定义 | 优先查 LOINC 官方术语与专业机构资料，记录**来源链接、编码、测量对象、量纲、必须区分的医学属性及证据适用条件**；未查到明确证据标“待医学核验” |
| 4 | 同名异义和别名 | 对照内置词典、解析器内置别名、用户别名、手动编辑入口；检查冲突；禁止模糊前缀匹配形成错误合并 |
| 5 | 单位属性 | 列出常用单位及**单位是否能够可靠互换**；遇到 %/fL、FEU/DDU、活性/质量等方法差异必须区分身份或要求人工复核 |
| 6 | 报告来源保护 | 验证文本单位和参考范围不被预设值覆盖；显示单位保持报告原格式与精度；未知单位不填猜测值 |
| 7 | 全入口一致 | 同一合成项目分别走固定格式粘贴、人工编辑、保存校验：能确认才通过，冲突时必须拦截并明确提示；报告数据导入不得存在 OCR 入口 |

## C. 特别禁止的自动归并
- `PDW-CV` 使用百分比属性、`PDW-SD` 使用体积分布宽度属性；`RDW-CV` 与 `RDW-SD` 同理。遇到报告单位和代码矛盾时**不是“纠正单位”**，而是**指标身份待核对**。旧 `PDW`/`RDW` 保留模糊身份，不按单位自动迁移历史记录。
- 比值方向和分子分母不可倒置：`AST/ALT` ≠ `ALT/AST`；`CKMB` ≠ `CKMB/CK`；`UREA` ≠ `UREA/CREA`。
- `PCT`（血小板压积）≠ `PCTIN`（降钙素原）；`CKMB` 活性 `U/L` 与质量浓度 `ng/mL` 不得无条件同轴换算。
- 计数与比例：`NEUT#` ≠ `NEUT%` 等全部白细胞分类；`NRBC%` 必须核对分母。
- D-二聚体 FEU 与 DDU **不得仅凭 D-二聚体名称当作同一计量标准**。
- 候选 LOINC 编码只用于医学指标概念核对，不构成医院或仪器认证，也不要求进行此类认证。

核验台账要**持续在同一份文件更新**，不要每次创建新的清单或重复计算已经核对过的指标；重新核验如有变更需注明原因和证据。

## 2026-10-16 最新用户修正规则：名称截断时按单位区分 CV / SD（覆盖此前过严禁令）

- 当报告的**中文名称相同或因栏宽被截断，末尾 CV/SD 未显示**，且上下文已确定属于同一“分布宽度”指标族时，允许使用**原报告明确给出的单位**自动区分测量身份：`%` → **CV**，`fL` → **SD**。适用于红细胞分布宽度 RDW、血小板分布宽度 PDW 等对应指标族。
- 例：`红细胞分布宽度 13.0 %` → RDW-CV；`红细胞分布宽度 41 fL` → RDW-SD；`血小板分布宽度 16.4 %` → PDW-CV；`血小板分布宽度 9.0 fL` → PDW-SD（前提：没有其他明确身份冲突）。
- **缺失单位、单位不是 %/fL、指标族不明或代码/完整中文名明确指向相反身份时，不得猜测**；进入待核对。显式完整代码或完整名称若与单位冲突，不能仅凭单位覆盖。
- 先前“通用 PDW 冻结自动归类”的限制现在**缩小为真正无法辨别的情况**：名称截断但已知指标族且有明确 %/fL 时可以自动判别；无单位或明确证据冲突仍冻结待核对。历史报告不得自动批量改写或重映射。
- 保留原始数值、小数精度、单位和参考范围；这是**新规则已确认**，但代码实现及测试验收需要单独核查，不得将规则提交视为功能已完成。
